# Future work (conservative)

Recommended next steps that keep the project focused on reproducible
analytics rather than new strategy ideas.

- Improve data-source reliability: add deterministic download checksums and
  retry logic for external data pulls.
- Expanded robustness testing: add additional walk-forward folds and
  parameter-sensitivity heatmaps.
- Cleaner reporting: generate a short static HTML or PDF report of
  `outputs/` artifacts for stakeholder review.
- Model-comparison: evaluate simple baselines (equal-weight, SPY overlay)
  and automated model-selection frameworks.
