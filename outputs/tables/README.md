# outputs/tables

Curated CSV and small-table artifacts for public review. Example files:

- `backtest_comparison.csv` — aggregated metrics by signal and period
- `final_comparison.csv` — selected configurations and key metrics
- `walk_forward_results.csv` — per-fold walk-forward summary
- `sector_map.csv` — mapping of tickers to sector ETFs

Small, cleaned CSVs are safe to commit and make inspection quick for
readers who do not want to re-run notebooks.
